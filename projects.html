Flow

    This application was designed to streamline a repetitive task I had in my previous job. It features two main functionalities:

  • Transaction Reconciliation - The core function processes two CSV files, comparing transactions and highlighting results. Matches are marked in green, while discrepancies are flagged in yellow for easy identification.

  • Interactive Cash Flow Management – Users can create, update, and delete transactions, allowing for more accurate financial projections.

Royal Stays

This project was developed as part of the Le Wagon Bootcamp. The application includes user authentication, allowing individuals to securely access and manage their profiles. A map feature enables easy navigation and visualization of castle locations. In addition, the app supports reservations - guests can book directly through the site, while hosts have tools to manage their bookings. The application is an intuitive and engaging platform for both guests and hosts.

# Portfolio Website

A personal portfolio website built with **HTML, CSS, and vanilla JavaScript** to showcase projects, skills, and contact information.  
This site is deployed using **GitHub Pages**.

---

## 🚀 Live Demo
Check out the live version here: [Portfolio on GitHub Pages](https://sabrinamaral.github.io/portfolio)

---

## 📂 Project Structure
- `index.html` – Main entry point of the website  
- `styles.css` – Custom styling for layout, colors, and responsiveness  
- `script.js` – Interactive features and DOM manipulation  
- `assets/` – Images, icons, and other static resources  

---

## ✨ Features
- Responsive design for desktop and mobile  
- Clean and modern UI built with pure CSS  
- Interactive elements powered by vanilla JavaScript  
- Easy to customize and extend with new sections or projects  

---

## 🛠️ Technologies Used
- **HTML5** – Semantic structure  
- **CSS3** – Styling and responsive design  
- **JavaScript (ES6+)** – Interactivity and dynamic content  
- **GitHub Pages** – Hosting and deployment
